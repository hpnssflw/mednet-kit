# Галерея и общее оформление: план реализации

> Исполнение в текущей сессии самим агентом. Ограничения пользователя запрещают делегирование без прямого запроса; отдельный журнал и коммиты по каждому шагу не нужны.

**Цель:** компактная галерея, прямое открытие экранов и единое оформление всей документации.

**Архитектура:** общее состояние оформления над маршрутами, CSS на корне документа, компактный поповер в существующем хедере; страницы примеров рендерят `ExampleScreen` без iframe. Галерея и главная используют сохранённые миниатюры выбранной темы.

**Стек:** React 19, React Router 8, Vite 8, TypeScript 6, `@mednet/ui` 2.2.1, существующие Node/Playwright проверки.

**Спецификация:** [2026-11-06-examples-gallery-global-appearance-design.md](../specs/2026-11-06-examples-gallery-global-appearance-design.md).

## Самостоятельный осмотр и исправления

Осмотрены desktop/mobile PNG Бренда и Солида, меню оформления, 200% текста и прямой реестр. Осмотр автора, не независимое ревью.

- Меню оформления на 320 px при 200% выходило за нижний край: добавлена внутренняя прокрутка по доступной высоте. `zoom-red` → `stage-ui-reviewed`, проверено переключение нижнего режима с клавиатурой/скроллом.
- Поиск в хедере Солида сжимался вместе с плотностью: ширина хедера задана отдельно от spacing компонентов; исправление осмотрено на desktop PNG.
- Удаление iframe вывело фиксированную боковую панель в общий viewport: её верх перекрывался хедером. Высота хедера измеряется ResizeObserver, боковая панель и навигация учитывают её; `sidebar-red` → `sidebar-green`, логотип и навигация действительно открыты на PNG.
- Новые React warnings (effect/state и Fast Refresh) устранены; адресный lint изменённых модулей — без предупреждений.
- Контраст новых текстовых элементов измерен через computed colors, canvas → sRGB luminance в 10 сочетаниях: минимум 5,74:1, ниже порога проверенных текстовых ролей нет.
- Оглавление: старые `scroll-mt-20` уменьшались вместе с плотностью и прятали заголовки за хедером. Отступ привязан к измеренной высоте хедера; `anchors-red.json` (3 сбоя из 4) → `anchors-green.json` (4/4, заголовки ниже хедера в обеих темах при 100/200%).
