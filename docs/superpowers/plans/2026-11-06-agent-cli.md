# Agent CLI Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans; работа выполняется основным агентом без делегирования. Новые согласования для уже разрешённой разработки не требуются.

**Goal:** Работающие install/sync/doctor для существующих установленных пакетов кита в отдельной ветке.
**Architecture:** Node ESM без runtime dependencies; общий read-only resolver для CLI и копируемого helper; plan/apply с ownership lock.
**Tech Stack:** Node >=22.12, node:test, TypeScript checkJs, pnpm/Turborepo.
**Spec:** docs/superpowers/specs/2026-11-06-agent-cli-design.md

## Global Constraints

- Private пакет @mednet/cli, bin mednet; существующие пакеты и release.yml не меняются.
- Изолированная ветка feat/agent-cli от 7262bdbc; основной checkout не меняется.
- Только legacy llms/exports в первой реализации; неподдержанный manifest блокируется.
- Никаких network/config execution в discovery/doctor и скрытой установки зависимостей.

## Review Focus

- Root/leaf resolution и две независимые версии в монорепозитории.
- Сохранность произвольных пользовательских bytes и unmanaged файлов.
- Ноль записей doctor/dry-run, включая lock/journal/cache.
- Symlinks/junctions и повреждённый ownership input.
- Partial write rollback и самостоятельность установленного helper.
