# Чат-блок `@mednet/ui` — черновик плана

> **Статус:** черновик по итогам обсуждения 2026-10-27, не к исполнению. Перед стартом — согласовать открытые вопросы (внизу) и расписать задачи по `superpowers:writing-plans`.

**Goal:** готовый фирменный блок чата в `@mednet/ui`: список сообщений, поле ввода, состояния. Рендер содержимого сообщений (markdown, код, блок-схемы) подключается снаружи через слот и не тянет тяжёлые зависимости в кит.

**Решение:** в общий UI-кит рендер markdown и схем не входит. Он нужен только чату, где ответ модели приходит потоком.

## Уровни

| Уровень | Что | Оценка | Куда |
|---|---|---|---|
| 1. Каркас | сообщения, ввод, автоскролл, состояния; без бэкенда | 2–4 дня | `@mednet/ui` (фирменный блок) |
| 2. Содержимое | стриминговый markdown, код, таблицы, mermaid, действия над сообщением | +3–5 дней | отдельный необязательный модуль или рецепт на docs-сайте |
| 3. Продукт | API модели, SSE/стриминг, история, tool calls, артефакты | зависит от задач | приложение, не кит |

Итого по киту (уровень 1 вместе с тестами, паритетом и документацией) — около недели.

## Уровень 1: каркас

- Сообщения: пузыри пользователя и ассистента, аватар, время, статус.
- Ввод: autosize `Textarea`, Enter — отправить, Shift+Enter — перенос строки, кнопки «отправить» и «стоп».
- Автоскролл к низу, но без перехвата прокрутки, если пользователь ушёл вверх; кнопка «к последнему».
- Состояния: пусто, загрузка, ошибка, повтор.
- Собирается из имеющегося: `Button`, `Textarea`, `ScrollArea`, `Avatar`, `Skeleton`.
- API без привязки к бэкенду: пропсы `messages`, `onSend`, `onStop`, статус.
- **Слот содержимого с первого дня:** проп `renderContent` (или `renderMessage`). Иначе позже придётся ломать API.

## Уровень 2: содержимое сообщений

- Стриминговый markdown: `streamdown` (дорисовывает незакрытые блоки, мемоизирует блоки) или `react-markdown` + `remark-gfm`. На каждом токене `react-markdown` перерисовывает всё сообщение, для потока он хуже.
- Санитизация обязательна (`rehype-sanitize`): вывод модели недоверенный.
- Код: `shiki` с темами на CSS-переменных (нужно для тёмной темы), кнопка «копировать».
- Mermaid:
  - только в браузере, клиентский компонент с ленивой загрузкой (`import()`);
  - во время стрима не рендерить, показывать плейсхолдер, рендерить по закрытию блока; при ошибке разбора показывать исходный код;
  - цвета из токенов через `themeVariables`, перерисовка при смене темы;
  - доступность: `<figure>` с `aria-label` или текстовым описанием.
- Действия: копировать, 👍/👎, перегенерировать; вложения, цитаты и источники.
- Ссылки с `rel="noopener noreferrer"`.

## Ограничения репозитория

- `src/components/**` сгенерирован, руками не править. Блок оформляется как фирменный модуль: ключ в `exports`, `pnpm --filter @mednet/ui gen:index`, раздел в `llms/brand.md`, запись в карте `BRAND` в `scripts/build-llms.mjs`, путь в `required` в `scripts/check-dist.mjs`.
- Вид — на обеих сторонах: `packages/ui/src/brand.css` и `packages/css/src/overrides.css`; тест паритета `apps/docs/tests/parity.spec.ts`. Эталон — shadcn Maia.
- Основа — Base UI: проп `render`, не `asChild`; зависимостей `radix-ui` быть не должно.
- Chrome/Edge 109: проверить markdown-стек и mermaid в job `chrome109`.
- Тёмная тема ([2026-10-27-dark-theme.md](2026-10-27-dark-theme.md)): блок работает в обеих темах, проверяется в visual- и axe-тестах.
- Тяжёлые зависимости (`mermaid`, markdown-стек) — только optional peer или отдельный модуль; нельзя утяжелять `@mednet/ui` для всех потребителей.
- Changeset `minor` (новый публичный модуль). Не публиковать, не запускать `pnpm version-packages` (`AGENTS.md`, `docs/releasing.md`).
