# Галерея примеров и общее оформление документации

Основание: согласованная пользователем композиция по образцу главной и уточнение от 2026-11-06: убрать промежуточный предпросмотр, открывать сам пример, перенести выбор оформления в хедер всей документации.

## Результат

- `/docs/examples` показывает восемь компактных миниатюр с короткими названиями в устойчивой асимметричной сетке. Образец — текущая главная: небольшие рамки, скругление, тень, разный ритм колонок. На телефоне — одна колонка. Поиск, категории, пустой поиск и сброс сохраняются.
- Клик открывает работающий экран по `/docs/examples/:id`, непосредственно в документе под общим хедером. Вложенного iframe, рамки «Компьютер/Телефон» и промежуточного описания нет. Старые адреса и сценарии остаются рабочими.
- В общем хедере есть компактный выбор «Бренд / Солид», палитры Солида и светлого/тёмного режима. Оформление действует на каркас, документацию, компоненты, портальные слои и примеры. Смена оформления сохраняет заполненные поля и состояние экрана.
- Выбор сохраняется между переходами и после перезагрузки. Явные параметры старых ссылок имеют приоритет при открытии ссылки. Недоступный или повреждённый localStorage не блокирует сайт. Начальное оформление применяется до первой отрисовки.
- Лаборатория тем использует то же состояние. Главная и галерея показывают миниатюры выбранного оформления, а не чужой палитры.

## Решения исполнителя

Композиция галереи фиксирована, как на главной. Сохраняются React, Vite, React Router, установленный `@mednet/ui` 2.2.1 и текущие CSS тем; новые зависимости не нужны. Полные экраны продолжают загружаться лениво. Миниатюры — предварительно сохранённые изображения: галерея не монтирует восемь приложений одновременно.

Единое состояние оформления размещается над маршрутами. Оформление синхронизируется с корнем документа; маршрут и параметры данных не служат ключом, сбрасывающим экран при смене темы. Изолированные `/examples/:id?embedded=1` остаются для генерации миниатюр и существующих проверок, но пользовательские переходы открывают обычную страницу.

## Источники и границы

Главная и существующие экраны осмотрены в браузере на 1440 и 390 px. Источник композиции — `src/docs/home.tsx`. Из библиотеки Director применяются: Primer navigation — различать переход и фильтрацию; Primer FormControl — подписанные настройки у ввода; Primer River — менять композиционный ритм, сохраняя порядок чтения. Бренд, API и размеры компонентов берутся из установленного кита, оформление сторонних систем не переносится.

Пакеты `mednet-kit`, публичный API, релизы и публикации в задачу не входят. В документационном репозитории уже есть многочисленные чужие локальные изменения: работа начинается с их копии, перенос меняет только файлы этой задачи после сверки с исходным снимком.

## Приёмка

- Галерея: 1440 / 768 / 390 / 320 px, обе темы и режимы, читаемые подписи, отсутствие переполнения, все восемь ссылок, поиск и сброс.
- Прямые страницы: восемь работающих экранов без iframe; глубокие и старые ссылки; переход обратно в каталог.
- Оформление: сохранение при навигации и reload, явные URL, legacy `compact`, неверные значения, закрытый storage; смена темы/палитры/режима без потери введённых данных.
- Хедер и поповер: клавиатура, Escape и возврат фокуса, 320 px и 200% текста, оба режима, палитра только для Солида.
- Адресные новые проверки, затем обязательные build / check / lint / test и применимые браузерные проверки документации. PNG desktop/mobile действительно открываются и оцениваются отдельно от прохождения тестов.
