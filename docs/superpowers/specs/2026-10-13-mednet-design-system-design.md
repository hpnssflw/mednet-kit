## 1. Цель и контекст

### Проблема

Четыре действующих сервиса — четыре стека, и акцентные цвета расходятся с брендбуком:

| Сервис | Стек | Акцент |
|---|---|---|
| mednet.ru | MODX + Bootstrap 4.1 + jQuery, Montserrat | `#e06b65` (насыщеннее бренда) |
| olimpiada.mednet.ru | Vite + React + antd + Tailwind v4 | `#d8827b` (близко к бренду) |
| pmsp-effectiveness-improvement.mednet.ru | статика, Montserrat + Onest | бордо `#8f3150` + золото — вне бренда |
| pmsp-project.mednet.ru | та же статика | тёмно-зелёный `#2e6b52` — вне бренда |

### Цель

Дать команде готовые пакеты, шаблоны и рецепты, чтобы **новые прототипы сразу были в бренде**, а существующие сайты могли подтянуть бренд **без переписывания**.

### Кто пользователь

Прототипы собирают **AI-агенты** (Claude Code, Cursor и т. п.) в руках разработчиков и не-разработчиков. Следствия:
- кит должен быть стеком, который агенты знают лучше всего;
- уход с бренда должен быть технически невозможен (линтер, отсутствие «чужих» цветов), а не только описан в документации;
- документация для агентов поставляется вместе с пакетом и не устаревает.

### Типы приложений (все четыре обязательны)

Публичные лендинги и отчёты; внутренние инструменты (админки, CRUD); пользовательские сервисы (кабинеты, регистрация, анкеты, тесты); дашборды с аналитикой (карта регионов — после v1).

### Не входит в v1

- Адаптеры/миграция существующих сайтов (только рецепты в документации, §15).
- Тёмная тема (семантический слой позволяет добавить позже).
- Версия для слабовидящих `[data-theme="a11y"]` — кандидат на v1.1.
- Storybook (примеры пишутся в CSF-формате, чтобы подключить его позже без переписывания).
- Фуллстек-стартер: авторизация, БД/ORM — отдельный подпроект после дизайн-системы.
- Библиотека в Figma (токены в DTCG-формате оставляют дверь открытой).
- Графики для HTML-шаблона (палитра доступна из `tokens.json` для любой библиотеки).
- Карта РФ по субъектам (`RussiaMap`) — `@mednet/charts` в v1 только тонкая обёртка над Recharts.
- Деплой docs-сайта и выбор домена — отдельная задача вне этапов 1–8.

### Прочее из брендбука

- **Шрифты:** Montserrat — Medium (500) для текста, SemiBold/Bold (600/700) для заголовков. Bebas Neue — допустим для промо-заголовков.
- **Иконки:** только контурные, в одном стиле; залитые запрещены.
- **Графика:** фирменный паттерн (линии + круг со стрелкой и плюсом); размытые цветные «капли» и круги на фоне.
- **Фото и иллюстрации:** светлые реалистичные фото; иллюстрации в единой гамме, без безликих и утрированных людей.
- **Логотип:** горизонтальный с дескриптором, вертикальный без дескриптора; охранное поле — ½ ширины знака. Использовать только оригинальный файл.
- **Tone of voice:** «научпоп» — на фактах, но понятным языком.

## 5. `@mednet/tokens`

### Формат

Цвета — DTCG JSON (формат DTCG 2025.10: `$value` цвета — объект `{colorSpace, components, hex}`; семантика — алиасы `{color.red.600}`). Типографика, радиусы, тени и движение — TS-константы пакета: `clamp()` и тени с прозрачностью в DTCG без потерь не выражаются.

### Слои

1. **Примитивы** — шкалы бренда.
2. **Семантика** — контракт shadcn + расширения.
3. **Защита** — сброс стандартной палитры Tailwind.

### Шкалы примитивов

Брендбуковые оттенки распределены по светлоте неравномерно (у red s1 и s2 обе ~600 по OKLCH), поэтому шкала **позиционная**, базовый цвет всегда `500`:

| Шаг | Источник |
|---|---|
| 50 | генерируется (светлее s6) |
| 100 | s6 |
| 200 | s5 |
| 300 | s4 |
| 400 | генерируется (середина между s3 и s4 в OKLCH) |
| **500** | **s3 — базовый цвет бренда** |
| 600 | s2 |
| 700 | s1 |
| 800, 900, 950 | генерируются (темнее s1, тот же тон, хрома уменьшается) |

Цвета: `red`, `blue`, `green`, `yellow`, `orange`, `violet`, `beige`, `peach`. Значения из брендбука сохраняются **точно**; генерация — в OKLCH скриптом сборки, результат фиксируется в DTCG JSON (не вычисляется в рантайме).

`graphite` — нейтральная шкала: `graphite-900 = #333333` (из брендбука), остальные шаги генерируются как нейтральный серый. Обязательные точки: `graphite-600 = #666666`, `graphite-400 = #8a8a8a`.

Примитивы **не гарантируют контраст** — гарантии даёт только семантический слой.

### Типографика

- `--font-sans`: Montserrat; `--font-display`: Bebas Neue (только промо-заголовки). Файлы Bebas Neue в v1 **не поставляются**: в @fontsource/bebas-neue нет кириллицы (§18 Q6); токен объявлен с фолбэком на Montserrat.
- Веса: текст 500, заголовки 600/700.
- Шкала: `xs` 13px, `sm` 14px, `base` 16px, `lead` 18px, `h4` 18px, `h3` 20px, `h2` `clamp(28px, 2.6vw, 38px)`, `h1` `clamp(28px, 3.2vw, 46px)`. Межстрочный: текст 1.5, заголовки 1.2.

### Форма, тени, движение

- Скругления компонентов задаёт стиль Maia (D16): кнопки и поля — `rounded-4xl` («пилюли»), карточки и аккордеоны — `rounded-2xl`. `--radius: 1rem` — база производной шкалы shadcn (`radius-sm…xl`) для своих компонентов.
- Отступы — стандартная шкала Tailwind (4px).
- Тени — мягкие, тёплые (тон beige-700 с низкой прозрачностью), 3 уровня: `sm`, `md`, `lg`.
- Движение: `--ease: cubic-bezier(.2, .7, .2, 1)`; длительности 150/250ms; `prefers-reduced-motion` отключает анимации.

### Защита

В Tailwind-точке входа: `@theme { --color-*: initial; ... }` — стандартная палитра удаляется, доступны только семантика и бренд-шкалы. `bg-red-500` в проекте означает **брендовый** red-500.

### Выходы сборки

| Файл | Для чего |
|---|---|
| `tokens.css` | CSS-переменные: примитивы `--mn-red-500`…; семантика дважды — с префиксом `--mn-primary: var(--mn-red-600)` и в именах shadcn `--primary: var(--mn-primary)`; база (`--radius`, `--mn-font-*`, `--mn-text-*`…) |
| `theme.css` | Tailwind v4 `@theme`-блок со сбросом палитры (импортируется `@mednet/ui` и шаблонами) |
| `tokens.ts` / `tokens.js` | Значения для JS (графики, antd-рецепт) |
| `tokens.json` | JSON с итоговыми значениями (без алиасов) для сторонних инструментов |

### Проверка контраста (в CI, валит сборку)

Все пары семантики «текст/фон» ≥ 4.5:1 (в том числе `foreground` и `muted-foreground` на `field`); `input`, `ring` к `background` и `muted` ≥ 3:1, `input` к `field` ≥ 3:1. Список пар задаётся в коде теста явно.

## 6. `@mednet/css` (статика)

- Состав: `tokens.css` + шрифты (@fontsource Montserrat 500/600/700, кириллица + латиница, woff2) + Basecoat (стиль Maia) с нашей темой + фирменные блоки + JS Basecoat.
- Порядок подключения: Basecoat → `@mednet/tokens/theme.css` (наши `:root`-переменные и `@theme` перекрывают нейтральную тему Basecoat) → базовая типографика → бренд-правки.
- Бренд-правки Basecoat — `src/overrides.css` (слой `components`, после Basecoat, селекторы Basecoat): только точечные исправления там, где Basecoat использует токен не в той роли, что наша семантика (заливка полей `--input` → `--field`, подсветка контурной кнопки → `--muted`), или где базовая типографика бренда протекает в компонент (размер заголовков `alert` и `toast`). Это уточнение D4 и правила v1 «без своего CSS»: своих компонентов и стилей сверх Basecoat нет, правки минимальны и проверяются тестами сборки и скриншотами.
- Tailwind-утилит (`flex`, `p-4`…) в `mednet.css` нет — как и в CDN-сборках Basecoat. Нужны утилиты — HTML-шаблон со сборкой (этап 5).
- Фирменные блоки (классы): `mn-header`, `mn-footer`, `mn-hero`, `mn-section`, `mn-pattern`, `mn-blob`, `mn-logo`, `mn-stat`. Пишутся как HTML-фрагменты с Tailwind-утилитами; CSS компилируется сканированием этих фрагментов.

## 15. Внедрение в существующие сайты (рецепты, не адаптеры)

**Правило: на существующих сайтах использовать только переменные с префиксом `--mn-*`.** Имена shadcn без префикса конфликтуют с чужими: Bootstrap 4 (mednet.ru) объявляет в `:root` свой `--primary: #007bff`, у pmsp-* есть свои `--accent` и `--muted`. Поэтому `tokens.css` и `fonts.css` подключаются **до** CSS сайта — тогда имена без префикса из `tokens.css` не перекрывают переменные сайта (`--primary`, `--accent`, `--muted`, `--border`, `--radius`…); **после** CSS сайта идёт только блок `<style>`, переназначающий переменные сайта на `--mn-*`. `mednet.css` на существующие сайты **не подключается**: он для новых страниц и сайтов без Bootstrap и других CSS-фреймворков — в нём сброс стилей (Tailwind preflight обнуляет отступы, списки, заголовки) и классы Basecoat с именами Bootstrap 4 (`btn`, `badge`, `card`, `alert`, `table`…); Basecoat лежит в `@layer`, неслойные правила Bootstrap побеждают, и компоненты получаются гибридными.

- **pmsp-*** (статика с CSS-переменными): подключить `tokens.css` + шрифты; переназначить свои переменные (`--accent`, `--accent-dark`, `--accent-tint`, `--ink`, `--muted`, `--line`, `--line-soft`, `--bg-warm`, `--font-display`, `--font-text`…) на `var(--…)` кита.
- **mednet.ru** (MODX + Bootstrap 4.1, переменных нет): подключить `tokens.css`; заменить `#e06b65` (108 вхождений в `style_new.css`) и `#3b3b3b` на переменные.
- **olimpiada** (antd): тема `ConfigProvider` из `@mednet/tokens` (TS-экспорт).
- **Любой Tailwind v4 проект без shadcn**: `@import "@mednet/tokens/theme.css"`.
