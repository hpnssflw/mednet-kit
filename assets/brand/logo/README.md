# Логотип ЦНИИОИЗ — рабочие SVG

Извлечены из векторов брендбука (`Брендбук ЦНИИОИЗ полный v8.pdf`, стр. 10 «Логотип»), растра нет.
Это временный источник: если дизайнеры пришлют оригинальные файлы, заменить ими.

| Файл | Вариант |
|---|---|
| `logo-horizontal.svg` | горизонтальный: знак + «ЦНИИОИЗ» + полный дескриптор (научно-исследовательский институт…) |
| `logo-horizontal-minzdrav.svg` | горизонтальный: знак + «Центральный институт организации и информатизации здравоохранения Минздрава России» |
| `logo-vertical.svg` | вертикальный без дескриптора: знак + «ЦНИИОИЗ» |
| `logo-mark.svg` | только знак |

Цвета как в брендбуке: знак `#d6867f`, текст `#000000`.
Правила брендбука: охранное поле — ½ ширины знака; вертикальный вариант — когда дескриптор становится нечитаемо мелким.

На этапе 4 (§17 спецификации) файлы оптимизируются (svgo), получают монохромные и инверсные версии и переезжают в `@mednet/ui` / `@mednet/css`.
