# Changesets

Любое изменение пакета `@mednet/*`, видимое потребителю, сопровождается changeset: `pnpm changeset`.
Все пакеты `@mednet/*` версионируются вместе (одна версия кита). `patch` — исправление, `minor` — новое и совместимое, `major` — ломающее, в том числе изменение бренда, меняющее внешний вид.

Публикует только GitHub Actions после merge PR «Релиз пакетов @mednet/\*». Процесс и правила — [docs/releasing.md](../docs/releasing.md).
